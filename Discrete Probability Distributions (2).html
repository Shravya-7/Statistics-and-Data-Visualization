Binomial Distribution

Counts the successes in n independent trials that each succeed with probability p. Each trial has two outcomes, and p stays the same on every trial.

Inputs
A positive whole number: 1, 2, 3, …

A number from 0 to 1, including both ends

Selected values
Number of trials, n
20
Probability of success, p
0.35
Distribution
X ~ Bin(20, 0.35)

XP(X = x)
Statistics for X ~ Bin(n, p)
Mean — E[X] = np
Variance — Var(X) = np(1 − p)
Standard deviation — σ = √Var(X)
Second moment — E[X²] = Var(X) + E[X]²
Skewness — (1 − 2p) / √(np(1 − p))
