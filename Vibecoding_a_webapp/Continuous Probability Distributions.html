Module 02 · Cloud computing

Exponential Distribution

Cloud Request Inter-arrival Time

Continuous waiting time
☁

Industry problem

A cloud application receives independent user requests at an illustrative average rate of λ = 12 requests per minute. The operations team studies the time between consecutive request arrivals to understand traffic patterns. This model describes inter-arrival time, not server response time.

Assumption: requests follow a constant-rate Poisson arrival process.

⚙

Input parameters

Requests per minute; must be positive
Seconds; must be non-negative
Seconds for conditional probability
Seconds; must be at least t₁

ƒ

Mathematical formulas

f(t) = λe−λt,   t ≥ 0

Density with λ expressed per second

E[T] = 1/λ   ·   Var(T) = 1/λ²

Mean in seconds; variance in seconds²

P(T ≤ t) = 1 − e−λt   ·   P(T > t) = e−λt

For conditional survival: P(T > t₂ | T > t₁) = e−λ(t₂−t₁)

Convert λ from requests/minute to requests/second by dividing by 60.

∑

Interactive calculations

Mean inter-arrival time—seconds
Variance—seconds²
P(T ≤ t)—Probability by threshold
P(T > t)—Probability beyond threshold
P(T > t₂ | T > t₁)—Conditional probability

Inter-arrival time (seconds) · Curve height is probability density per second; shaded areas represent probabilities.

✦

Memoryless property and interpretation

—

Memoryless property: If no request has arrived yet, the distribution of the additional waiting time is the same as it was at the start. In other words, having already waited t₁ seconds does not change the probability of waiting at least another t₂ − t₁ seconds.

Central Limit Theorem

Warehouse Processing Time

Sampling distribution
▥

Industry problem

A warehouse tracks the time needed to pick, pack, and prepare an order for dispatch. Individual order times can vary widely. Managers study the average processing time across groups of orders to plan staffing and daily workloads.

⚙

Input parameters

Average processing time in minutes
Variation in minutes
Orders in each sample group
Groups to compare in the study
ƒ

Mathematical formula

X̄ ≈ N(μ, σ²/n)
SE = σ / √n

X̄ = sample mean · SE = standard error · n = sample size

∑

Interpretation of results

The Central Limit Theorem explains that, under suitable conditions, averages from sufficiently large independent samples tend to follow an approximately normal distribution—even when individual processing times are not normally distributed.
